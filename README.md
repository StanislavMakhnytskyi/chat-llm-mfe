# chat-llm-mfe

Nx workspace bootstrap for a React 19 chat shell with Module Federation 2.0+, a shared Zustand store, and Tailwind CSS v4.

## Apps

- `host` on `http://localhost:3001`
- `sidebar-remote` on `http://localhost:3002`
- `chat-remote` on `http://localhost:3003`

## Commands

- `npm install`
- `npm run dev`
- `npm run dev:host`
- `npm run dev:sidebar`
- `npm run dev:chat`
- `npm run build`
